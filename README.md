# 养老保险记录簿

无框架、无构建依赖的个人缴纳记录工具。

## 使用
直接打开 index.html，或在项目目录运行 `python -m http.server 8765 --bind 127.0.0.1`，访问 http://127.0.0.1:8765。
同一浏览器、同一来源保存自己的记录；文件页面与 HTTP 页面使用不同存储空间。切换前请导出备份。

## 文件
- index.html：语义结构、表单和确认弹窗。
- styles.css：仪表盘样式、环形进度、响应式布局。
- pension-core.js：纯函数，数据迁移、校验、年度及累计计算。
- app.js：DOM 交互、记录增删改、存储、备份。
- tests/core.test.cjs：16 项独立测试，运行 `node tests/core.test.cjs`。

## 计算规则
起止月份均计入，累计实缴 = 总跨度 - 中断扣除。参考目标可设 1–60 年。
指定所属年份的中断会扣除该年月份；年份未分配的扣除仅扣累计值，年度列表明确显示差额。
时间轴的格子表示该年月份数量，不推断具体停缴月份。
历史 pension_data_v2 和 deductMonths 备份兼容。所有导入先验证，确认后替换；错误导入不覆盖数据。
日期、整数月数、年度扣除上限、累计上限、年份范围均验证。记录文本通过 textContent 渲染。
本机存储失败会提示导出；建议定期备份。

## 回滚
Git Bash 下运行 `.design/v2/ROLLBACK.sh` 恢复改造前首页。脚本保留新拆分文件和用户数据。
测试回滚到副本：`.design/v2/ROLLBACK.sh .design/v2/rollback-test.html`。

## 自动截止日期
截止日期跟随北京时间今天所在月份，打开、导入、切回页面和每分钟检查时自动更新；跨月会重新计算并保存，不需要手动修改截止年月。仍以月份为单位，含本月。测试：node tests/today.test.cjs。
